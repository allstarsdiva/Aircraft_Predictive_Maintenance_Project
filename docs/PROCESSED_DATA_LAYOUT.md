# Processed Data Layout

Generated by: `scripts/export_processed_data.py`

Each processed table is stored under its aircraft subsystem. `data/processed/manifest.json` records file dimensions, byte sizes, descriptions, and SHA-256 checksums.

```text
data/processed/
├── manifest.json
├── engine/
│   ├── fd001_labeled_features.csv
│   └── fd001_unit_split.csv
├── battery/
│   ├── discharge_cycles.csv
│   └── soh_features.csv
├── hydraulic/
├── fuel_system/
└── landing_gear/
```

Avionics is excluded from the project and is not recorded in the processed-data manifest.
